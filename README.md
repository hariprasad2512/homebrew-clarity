# homebrew-clarity

Homebrew tap for [Clarity](https://github.com/hariprasad2512/Clarity), a
minimal open-source todo app for macOS.

```sh
brew tap hariprasad2512/clarity
brew install --cask clarity
```

The Cask is bumped automatically by the Clarity repo's release workflow —
see `hariprasad2512/Clarity/.github/workflows/bump-cask.yml`.
